# Icon Placeholders

The extension needs actual PNG icons. You can:

1. Use the SVG as a template and convert to PNG using any image editor
2. Or create simple PNG files (16x16, 48x48, 128x128) with a bell icon

For now, the extension will work without icons but Chrome will show a warning.

To convert SVG to PNG:
- Use an online tool like cloudconvert.com
- Or use ImageMagick: `convert icon128.svg -resize 128x128 icon128.png`
- Or just create simple colored squares for testing
